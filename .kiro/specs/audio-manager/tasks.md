# Implementation Plan

## Branches

**Base**: `feature/audio-manager`

| Branch | Tasks | Goal |
|--------|-------|------|
| `feature/audio-manager-core` | 1-4 | BGM/SE 再生・音量・サウンド切替・永続化・シーン自動 BGM が動作する状態 |
| `feature/audio-manager-button-se` | 5-6 | 全 UI ボタンにクリック SE が自動適用され、上書き・除外が機能する状態 |

## Tasks

### Branch: `feature/audio-manager-core`

- [ ] 1. オーディオ純粋ロジックの構築
  - [ ] 1.1 (P) 音量計算ロジックを実装する
    - 音量値を有効範囲 (0〜1) へ丸める処理
    - カテゴリ音量・クリップ基準音量・サウンド有効状態から実効音量を求める計算 (無効時は常に無音)
    - エンジン非依存の独立アセンブリとして作成する
  - [ ] 1.2 (P) SE 再生ソース選定ロジックを実装する
    - 空きソースを優先し、全ソース使用中は最も古い再生を奪う決定論的な選定処理
  - [ ] 1.3 純粋ロジックのユニットテストを作成する
    - 丸め (範囲内・負値・1 超・NaN)、実効音量 (ゼロ音量・サウンド無効)、ソース選定 (空きあり・奪取・単一境界) を検証
    - 各テストに日本語の説明属性を付与する
  - _Requirements: 2.4, 3.4, 3.5, 3.6_

- [ ] 2. オーディオ識別子とレジストリの構築
  - [ ] 2.1 (P) SE/BGM 識別子とレジストリを実装する
    - SE・BGM それぞれの識別子定義 (SE には「SE なし」を表す値を含む)
    - 識別子からクリップ (BGM は基準音量込み) を解決する対応表アセット
    - シーン名から BGM 識別子を解決するマッピング
    - 未登録識別子は null 返却とし、エディタ上で割当漏れ・シーン名誤りを警告する検証を付ける
  - [ ] 2.2 レジストリアセットを作成し起動時ロードを組み込む
    - Resources 配下にアセットを配置し、起動時に同期ロード・欠落時は例外で fail-fast
  - _Requirements: 6.1, 6.2, 6.3_

- [ ] 3. オーディオ再生・音量・永続化の中核実装
  - [ ] 3.1 オーディオ状態と設定データを実装する
    - BGM/SE 音量・サウンド有効状態・再生中 BGM の状態保持
    - 永続化用データ (既定値: 音量 1.0/1.0・サウンド有効) とイミュータブルスナップショット
  - [ ] 3.2 再生ホストを実装する
    - BGM 用 2 ソースのクロスフェード切替・フェード停止・即時音量反映 (フェード中の音量変更はトゥイーン破棄後に目標再計算)
    - SE プール (既定 8 本) でのワンショット多重再生
  - [ ] 3.3 オーディオサービスを実装する
    - SE/BGM 再生指示 (同一 BGM は継続、未登録はログのみで進行継続、BGM 未再生時の停止は無操作)
    - カテゴリ別音量・サウンド有効/無効の設定と再生中音声への即時反映
    - 設定変更時の永続化と、起動時の読込 (データ欠落・破損時は既定値で継続しエラーログ)
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 2.1, 2.2, 2.3, 3.1, 3.2, 3.3, 3.6, 4.1, 4.2, 4.3, 4.4_

- [ ] 4. DI 統合・シーン BGM 自動再生・メニュー連携
  - [ ] 4.1 DI 登録と再生ホストの配置を行う
    - RootLifetimeScope プレハブへ再生ホストを配置し、契約と実体の両方で解決可能に登録
    - DI 経路外からサービスへ到達する静的ブリッジをコンテナ構築時に初期化する
  - [ ] 4.2 シーンロード連動の BGM 自動再生を実装する
    - シーンロード完了イベントを購読し、マッピングされた BGM を再生 (マッピングなしは現状維持、同一 BGM は途切れず継続)
  - [ ] 4.3 メニューダイアログのサウンドトグルを委譲へ改修する
    - トグル操作をオーディオサービスのサウンド有効/無効切替へ委譲し、メニュー設定データから音関連の保持を撤去
    - 消音は再生停止ではなく無音化とし、再有効化で即復帰することを確認
  - [ ] 4.4 コア機能の統合動作を確認する
    - シーン遷移 (Title → Home → Shop 等) で BGM が継続・切替されること
    - 音量変更の即時反映とアプリ再起動後の設定維持
    - レジストリ割当を外した識別子の再生がログのみで進行継続すること
  - _Requirements: 1.2, 3.2, 3.6, 3.7, 4.1, 4.2, 5.1, 5.2, 5.3, 6.2_

### Branch: `feature/audio-manager-button-se`

- [ ] 5. ボタンクリック SE の自動適用
  - [ ] 5.1 ボタン一括走査と既定 SE 付与を実装する
    - シーン内 (非アクティブ含む) および任意階層以下の全ボタンへ既定クリック SE リスナーを付与
    - 二重付与防止マーカーと、上書きコンポーネント付きボタンのスキップ
    - シーンロードイベントから走査を起動する
  - [ ] 5.2 ダイアログ生成時の自動適用フックを追加する
    - ダイアログ生成ファンネルの依存注入直後に階層走査を呼び出す
  - [ ] 5.3 SE 上書きコンポーネントと動的生成対応を実装する
    - ボタン単位で別 SE / SE なしを指定できるコンポーネント (自己配線は静的ブリッジ経由)
    - 動的生成されるセル系プレハブ (ショップ商品・ガチャ・クローゼットセル等) へ付与
  - _Requirements: 7.1, 7.2, 7.3, 7.4_

- [ ] 6. ボタン SE の統合検証
  - [ ] 6.1 全経路のクリック SE 動作を確認する
    - シーン静的ボタン・ダイアログ内ボタン・動的生成セルボタンで既定/上書き SE が鳴ること
    - SE なし指定ボタンの無音と、ロジック結果 SE の明示再生手段が併存すること
    - DebugPanel のボタンが対象外であること (鳴っても実害なしの確認のみ)
  - _Requirements: 7.1, 7.2, 7.3, 7.4, 7.5_
