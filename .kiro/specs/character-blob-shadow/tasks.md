# Implementation Plan

## Branches

**Base**: `feature/character-blob-shadow`

All tasks are implemented in the base branch.

## Tasks

### Branch: `feature/character-blob-shadow`

- [x] 1. (P) 影用スプライトアセットを作成する
  - 256×256 の白→透明の放射状グラデーション画像を作成し、キャラクターアート配下のテクスチャ置き場に配置する
  - Sprite としてインポート設定し、1 ワールド単位 = スプライト直径となるよう PPU を 256 に設定する
  - 色味は画像に焼き込まず、表示側の color 制御で調整できる白素材とする
  - _Requirements: 1.1_

- [x] 2. (P) 影の調整用 View コンポーネントを実装する
  - 幅・高さ (0以上)・不透明度 (0〜1)・オフセットを Inspector で調整できる受動 View を作成する
  - エディタでの値変更時と実行時初期化の両方で、調整値を自身のスケール・位置・スプライト色の透明度へ反映する
  - SpriteRenderer を必須コンポーネントとし、未設定時はエディタで自動取得、実行時に欠落している場合はクラス名付きエラーログを出して反映を中断する
  - ロジックを持たない View 層とし、DI 登録は行わない
  - _Requirements: 3.1, 3.2, 3.3, 3.4_

- [x] 3. Home 用キャラクタープレハブに影を組み込む
  - Home 用 Character プレハブの Flipper 直下 (CharacterView の兄弟) に影オブジェクトを追加し、スプライトと View コンポーネントを配線する
  - 描画順は Default レイヤー・sortingOrder 50 (SortingGroup 内でキャラパーツより背面) をプレハブ上で設定する
  - 影の色 (黒系 + 透過)・サイズ・足元位置の初期値を設定する
  - Timer 用 Variant プレハブおよび両シーンのインスタンスに影が伝播しており、オーバーライドで除去されていないことを確認する
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 2.1, 2.2, 2.3, 4.1, 4.2_

- [x] 4. Timer 完了演出で影を非表示にする
  - 完了演出の飛び出し開始時 (拡大・描画順変更と同じタイミング) に影オブジェクトを非アクティブ化する処理を既存の演出 View に追加する
  - 影の参照が未設定の場合は何もしない (null 許容)
  - Timer シーンのインスタンスに影の参照を配線する
  - _Requirements: 2.3_

- [x] 5. 全シーンで影の表示を検証する
  - Home: 表示・描画順 (床より前面/キャラより背面)・歩行/走行中の接地追従・左右反転・待機の呼吸中に影が変形しないこと・着せ替え後の表示維持を確認する
  - Timer: Focus (Run) 中の同一見た目・Break の寝そべり中に影が変形しないこと・Pause/Resume・Complete 演出開始時の非表示を確認する
  - 共通: Inspector 調整値の即時反映・キャラクター非アクティブ化への連動・複数アスペクト比での見え方を確認する
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 2.1, 2.2, 2.3, 3.4, 4.1, 4.2_
